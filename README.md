## Introduction

Security hardening is a crucial aspect of maintaining a secure computing environment. This repository provides scripts that automate the process of securing your Windows and Linux machines. These scripts cover a range of security measures, from basic configurations to advanced protections.

## Features

- **Windows Security Scripts**: Enhance the security of your Windows operating system with automated scripts.
- **Linux Security Scripts**: Improve the security of your Linux distributions with easy-to-use scripts.
- **Regular Updates**: Stay up-to-date with the latest security practices and updates.
- **Comprehensive Documentation**: Detailed instructions and explanations for each script.

## Installation

To get started, clone the repository to your local machine:

```bash
git clone https://github.com/Resident-Fortress/SecureShell-Lite.git
```

Navigate to the directory:

```bash
cd SecureShell-Lite
```

## Usage

Each script is located in its respective directory (`windows/` or `linux/`). Follow the instructions provided in the README files within these directories to execute the scripts.

Example for Windows 10/11:

```bash
cd windows
./secure_windowsClient.ps1
```

Example for Linux:

```bash
cd linux
./secure_linux.sh
```

## Best Practices

- **Regular Updates**: Keep your systems and scripts updated to protect against the latest threats.
- **Backup**: Always backup your data before running security scripts.
- **Review Scripts**: Review the scripts to understand the changes they will make to your system.
- **Least Privilege**: Run scripts with the least privilege necessary to minimize potential damage.
